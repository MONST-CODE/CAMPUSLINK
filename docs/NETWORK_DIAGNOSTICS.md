# Network diagnosis and scoped experiments

A scan is requested only by a user action; fresh BSS entries are read after a Windows completion notification. Windows may deny WLAN information based on location/privacy policy. Save no credentials in CAMPUSLINK; the native profile stays in Windows. The scope names exactly one permitted Windows profile and BSSID, one numeric IPv4 endpoint, an optional controlled DNS name, and limits. Scan entries expire for handoff after two minutes. The profile association, socket bind/interface option and best-route evidence prevent attribution to an unrelated interface. A post-probe check rejects results after an observed profile/BSSID/address change.

- One host-owned switch at a time, one optional previous-profile rollback, no unattended switching. A manual test requires explicit consent. An assisted choice also needs fresh measured candidates, score coverage, a ten-point improvement and cooldown. The previous profile is considered for rollback only if Windows reported its BSSID and usable IPv4 before the switch. Rollback does not claim application connectivity has been validated on that previous profile.
- No BSSID wildcard, MAC spoofing, DHCP saturation tests, subnet probing or Internet fallback. No static IP is applied. Cancel is cooperative; a pending ICMP operation has a 350 ms timeout and OS driver calls can add latency. During a pending connect, cancellation requests disconnect of the application's host interface; use on a local console. Stop itself does not authorize a new rollback action.
- APIPA or missing IPv4 is a symptom, not a known DHCP failure or conflict. Gateway and endpoint ICMP can be filtered; losses are ICMP non-replies, not measured data-plane loss. DNS configuration is distinct from resolution. If configured, the DNS probe verifies one controlled A record through the interface's IPv4 resolver (one UDP exchange, no CNAME chasing, DoH, or Internet fallback). An optional DNS test failure prevents successful handoff validation. Without a DNS name, only resolver configuration is checked.
- CLP1 samples one bounded TCP round trip, with 1–64 KiB in each direction and latency-inclusive goodput; the application does not claim line rate or general Internet availability. Launch `python tools/clp1_server.py --bind <authorized-server-ipv4> --allow <single-client-ipv4> --port 8123 --seconds 120` on the agreed private lab host. Traffic is plaintext synthetic bytes, with no credentials. Restrict the server at the firewall as well; this is not an Internet/public service. `CLP1 <size>\n` → `RDY1` → byte payload → `ACK1` → `GO1\n` → exact payload echo. The server handles one request at a time, with a deadline and one allowed peer.

## Candidate 0.2.0 experiment policy

A scope file can contain up to four complete `version=1` blocks separated by `---` on its own line. Each block explicitly authorizes one saved profile and BSSID. Ordered `sizes` may list up to three distinct values of 1–64 KiB; `transfer_repetitions` accepts 2–5 subject to 1 MiB total CLP1 payload per candidate (upload plus download). `settle_ms` is 200–2000. `require_gateway_reply=true` makes gateway ICMP mandatory for initial validation; an absent route always fails. A configured DNS name must resolve to the authorized address via the selected interface's resolver. CLP1 requests are paced at least 1050 ms apart. See `config/test_scope.example.conf`.

A single STA runs candidates sequentially. At most two independent physical PnP devices with different lab endpoints run in one wave. The UI can report overlapping validated observation windows, not simultaneous RF frames, and leaves the radio ceiling unknown. Restoring the previous association after error or cancellation is attempted once only if `rollback=true` and the captured association was usable; it revalidates the exact profile, BSSID and usable IPv4/gateway without active probes. The native restoration attempt can take up to about 15 seconds. Otherwise cancellation does not claim that the original host state was restored. No simulated address or lease is ever applied to Windows.
