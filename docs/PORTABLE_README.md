# CAMPUSLINK portable — Windows 11 x64

**FR.** Extrayez tout le ZIP, puis lancez `CampusLink.exe` à côté de `SDL3.dll`. L’application s’ouvre sur **Connexion Wi-Fi** : cliquez sur **Rechercher les réseaux**, sélectionnez un réseau, puis **Connexion normale** ou **Connexion assistée directe**. Les étapes affichées (association, adresse IP, Internet) sont celles que Windows a confirmées. Si le profil manque ou qu’un portail demande une identification, utilisez les boutons proposés ; CAMPUSLINK ne contourne aucune authentification.

**EN.** Extract the entire ZIP and run `CampusLink.exe` next to `SDL3.dll`. The app opens on **Wi-Fi connection**: **Search for networks**, select a network, then **Connect normally** or **Connect with assistance**. Progress steps (association, IP address, Internet) are those Windows confirmed. For a missing profile or a captive portal, use the offered buttons; CAMPUSLINK never bypasses authentication.

No driver installation or elevation is required when Windows grants Wi-Fi access (location permission may be requested for scanning). Vulkan is preferred; SDL software rendering is the fallback. The research lab (virtual clients, scheduler models, CLP1 trials) is separate, opt-in and never runs automatically.
