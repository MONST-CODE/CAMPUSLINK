# Test plan

- `build.bat test`: native Debug core contracts, SDL window/quit, eleven ImGui software panels, read-only Windows interface inventory and the offline capacity profiler. `release-all` repeats core/smoke tests in both configurations and retests the extracted Release archive.
- `bash tests/integration/sdl-host-smoke.sh <SDL-include> <SDL-shared-lib-dir>`: GCC direct Debug/Release, core tests, SDL/ImGui headless, argument rejection and invalid video driver rejection. ImGui must be present under `third_party/imgui`. This is not an ABI validation for Windows.
- `python3 tests/integration/clp1_loopback.py`: local TCP protocol round trip and byte-cap rejection. This does not test Windows WLAN socket binding.
- Windows CI also runs `python tests/integration/clp1_native.py <CampusLink.exe>` to exercise the production Winsock transfer against a fixed loopback listener at three sizes and reject an invalid reply. This does not test physical routing.
- Workflow uses a checkout containing a space, `doctor`, invalid command code, `package` and `release-all`, retaining logs and artifacts. Check the [0.2.0 report](reports/CANDIDATE_0.2.0.md) for executed runs and outcomes. See the [historical 0.1.0 report](reports/FINAL_DELIVERY_REPORT.md) for baseline evidence.
- [Field tests on a Windows 11 client](WINDOWS11_VALIDATION.md): confirm adapter/PHY source, scope refusal, location granted/refused, WLAN service unavailable, native scan, no usable IPv4 (observe only), controlled endpoint with and without DNS, authorized handoff and rollback on a dedicated lab profile. Repeat resize/minimize/restore, Vulkan startup/fallback, and launch on a clean compatible Windows machine. Tests that change host connectivity are operator-controlled on-site only.
