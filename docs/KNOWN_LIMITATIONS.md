# Known limitations

- Windows Server CI cannot replace Windows 11 client, WLAN radio, Dell AX201, visible display, or Vulkan device-loss acceptance. SDL renderer is the tested fallback where headless tests run. Vulkan runtime failure switches to software instead of recreating Vulkan state in place.
- Physical testing is IPv4-only and manually authorized. The app does not automate repeated switching, discover arbitrary scopes, benchmark unconfigured destinations, or transmit virtual-client traffic. CLP1 rate includes protocol RTT and uses one small exchange. There is no captive portal verdict or automatic authentication root-cause classification.
- A scope permits one exact BSSID/profile at a time; observing multiple candidates needs sequential operator-authorized scoped tests. A mixed or stale history cannot produce a trusted automatic result. Weights and theme are session-only. App reports do not contain password material; the user-supplied scope does contain local test identifiers and should not be committed.
- WLAN role concurrency, several channel-width details and Wi-Fi Direct/secondary STA combinations are unknown. Present PnP/IP Helper inventory is not a full inventory of disabled/disconnected devices with no interface representation.
- Profiler memory is accounted conservatively, not process peak RSS. No rendering FPS claim. No bitwise build reproducibility or separate PDB ZIP is asserted.
